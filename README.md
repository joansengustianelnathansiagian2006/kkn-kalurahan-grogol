## 📌 Tentang Proyek

Proyek ini dikembangkan dalam rangka kegiatan **Kuliah Kerja Nyata (KKN)** di **Kalurahan Grogol**. Platform ini dirancang untuk mempublikasikan potensi kelurahan, transparansi program kerja KKN, berita lokal, serta menyediakan sistem manajemen konten (CMS) berbasis admin untuk mempermudah pengelolaan data.

---

## ✨ Fitur Utama

* **📄 Landing Page Informasi Kalurahan**: Profil desa, visi & misi, serta potensi daerah Grogol.
* **📰 Manajemen Berita & Kegiatan**: Publikasi artikel, dokumentasi acara, dan transparansi proja KKN.
* **🔐 Portal Admin Terproteksi**: Dashboard manajemen konten khusus admin dengan autentikasi aman.
* **⚡ Database Terintegrasi**: Pengelolaan data secara dinamis dan *real-time*.
* **📱 Desain Responsif**: Tampilan optimal di perangkat smartphone, tablet, maupun komputer.

---

## 🛠️ Teknologi yang Digunakan

* **Framework**: [Next.js](https://nextjs.org/) (App Router)
* **Styling**: [Tailwind CSS](https://tailwindcss.com/)
* **Database & Auth**: [Supabase](https://supabase.com/) (PostgreSQL)
* **Database ORM**: [Prisma](https://www.prisma.io/)
* **Deployment**: [Vercel](https://vercel.com/)
